# zAgent 全生命周期管理 - 需求设计

## 一、背景与目标

ClawParty 中每个 AI agent 是一个独立的 zeroclaw daemon 进程，有独立的配置、端口和生命周期。

**当前问题：**
- 侧边栏只显示 agent 名称 + 删除按钮，状态不可见
- Agent 离线时用户仍可输入消息，发送后才报 WebSocket 错误
- 无法从 UI 启动/停止 agent
- 看不到端口、PID、错误信息

**目标：让 agent 的状态可见、可控、可恢复。**

---

## 二、用户故事（按优先级）

### P0 - MVP

- **US-1** As a user, I want to 在侧边栏看到每个 agent 的实时状态，So that 我知道哪些 agent 可以使用
- **US-2** As a user, I want to 当 agent 离线时聊天输入框自动禁用并显示提示，So that 我不会浪费时间输入无法发送的消息
- **US-3** As a user, I want to 通过 UI 启动/停止 agent，So that 我不需要手动操作后端
- **US-4** As a user, I want to 当 agent 启动失败时看到明确的错误原因，So that 我能快速定位问题

### P1 - 第二迭代

- **US-5** As a user, I want to 一键重启出错的 agent
- **US-6** As a user, I want to 查看 agent 的运行详情（端口、PID、启动时间）
- **US-7** As a user, I want to 一键启动/停止所有 agent

### P2 - 未来增强

- **US-8** 状态历史记录
- **US-9** 自动重启策略配置

## 六、交互细节

### 启动流程
1. 用户点击 [▶ 启动]
2. 前端乐观更新状态为 `starting`，按钮禁用
3. 调用 `POST /api/agents/{name}/start`
4. 开始轮询状态（每 2 秒）
5. 状态变为 `running` → 停止轮询，提示成功
6. 状态变为 `error` → 停止轮询，显示错误信息

### 停止流程
1. 用户点击 [■ 停止]
2. 弹出确认对话框
3. 确认后调用 `POST /api/agents/{name}/stop`
4. 状态更新为 `stopped`

### 重启流程（P1）
1. 调用 stop → 等待 stopped
2. 调用 start → 进入启动流程

### 删除流程
1. 弹出确认对话框："确定删除 {name}？此操作不可恢复。"
2. 如果 status = running，先调用 stop
3. 调用 `DELETE /api/agents/{name}`
4. 从列表移除，如果是当前选中的 agent，切换到其他 agent

### 状态轮询策略
```
starting → 每 2 秒轮询，直到 running/error
running  → 每 30 秒轮询（健康检查）
其他状态 → 不轮询
```

## 七、实现方案

### 前端改动

| 文件 | 改动内容 |
|------|---------|
| `ChatSidebar.vue` | 添加状态指示器、启动/停止按钮、状态文本 |
| `App.vue` | 监听 agent.status，动态禁用输入框，显示状态提示 |
| `chatService.js` | 已有 startAgent/stopAgent，确认接口完整 |

新增组件（可选，也可内联实现）：
- `AgentStatusDot.vue` — 状态圆点 + 动画
- `useAgentPolling.js` — 轮询逻辑 composable

### 后端 API（已有，无需改动）

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/agents` | 获取所有 agent 状态 |
| POST | `/api/agents/{name}/start` | 启动 agent |
| POST | `/api/agents/{name}/stop` | 停止 agent |
| DELETE | `/api/agents/{name}` | 删除 agent |

## 八、MVP 验收标准

- [ ] 侧边栏每个 agent 显示状态圆点（颜色正确）
- [ ] `starting` 状态有旋转动画
- [ ] `running` 状态显示端口信息
- [ ] `error` 状态显示错误简述
- [ ] 启动/停止按钮根据状态正确启用/禁用
- [ ] `running` 状态：输入框可用
- [ ] 非 `running` 状态：输入框禁用 + 对应提示文案
- [ ] 删除操作有二次确认对话框
- [ ] `starting` 状态自动轮询，变为 `running`/`error` 后停止
