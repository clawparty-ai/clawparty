### Playwright 自动化覆盖范围

```typescript
// 推荐项目结构
tests/e2e/
  ├── fixtures/
  │   ├── test-data.ts        // 测试数据集中管理
  │   └── server.ts           // 注册服务器 mock
  ├── pages/
  │   ├── join-party.page.ts  // Page Object: 加入组织页面
  │   ├── agent.page.ts       // Page Object: Agent 管理页面
  │   └── chat.page.ts        // Page Object: 聊天页面
  ├── happy-path/
  │   ├── TC-P-001.spec.ts
  │   └── TC-P-002.spec.ts
  └── error-cases/
      ├── invite-code.spec.ts  // TC-E-001 ~ TC-E-006
      ├── server.spec.ts       // TC-E-007 ~ TC-E-008
      ├── username.spec.ts     // TC-E-009 ~ TC-E-010
      └── duplicates.spec.ts   // TC-E-011 ~ TC-E-012
```

### 各步骤自动化策略

| 步骤 | 自动化方式 | 说明 |
|------|-----------|------|
| 启动 ZTM Agent | Bash / `child_process` | `ztm run agent`，等待端口就绪 |
| 页面导航与表单操作 | Playwright | 全程浏览器自动化 |
| 表单前端校验 | Playwright | 验证 DOM 错误提示 + 无网络请求 |
| API 返回值验证 | Playwright 网络拦截 | `page.on('response', ...)` |
| 服务器离线场景 | 进程控制 + Playwright | 停止注册服务器进程后执行 |
| 重复操作场景 | 状态依赖 or 独立 fixture | 建议用 API 预置状态而非依赖前序用例 |
| AI 回复验证 | Playwright + 轮询 | 等待回复气泡出现，超时 30s |
